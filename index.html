기본 사용법
왼쪽 일정 카드를 클릭하면 이동 수단·소요 시간·일정 내용이 펼쳐지고, 오른쪽 지도에 출발지·도착지 마커가 표시됩니다. 카드 안의 "네이버 지도에서 길찾기 열기" 버튼을 누르면 실제 길찾기 화면으로 바로 이동합니다.

지도에 표시되는 선
지도 위 선은 기본적으로 출발지·도착지를 이은 직선(점선)일 뿐, 실제 도로 경로가 아닙니다. 다만 "자동차" 일정은 서버(Cloudflare Worker + NCP Direction5 API)에서 실제 도로 경로를 가져와 실선으로 표시하고, 소요 시간도 실시간 값으로 자동 교체됩니다 ("(실시간)"으로 표시). 자동차 외 이동수단(버스·도보 등)은 NCP가 경로를 계산해주지 않기 때문에 직선과 미리 입력해둔 예상 시간이 그대로 표시됩니다.

"네이버 지도에서 길찾기 열기" 버튼
이 버튼은 네이버 지도에서 실제로 그 두 장소를 길찾기 해봤을 때 나온 URL을 그대로 가져와 쓴 것이라, 누르면 출발지·도착지가 이미 채워진 길찾기 화면으로 정확히 이동합니다.

새 일정 추가하기
새로운 일정을 추가할 때는 네이버 지도에서 그 두 장소로 길찾기를 한 번 직접 실행해본 뒤, 주소창에 뜨는 URL 속 좌표·장소ID 값을 복사해서 데이터에 넣어야 위 버튼이 정확하게 동작합니다.
